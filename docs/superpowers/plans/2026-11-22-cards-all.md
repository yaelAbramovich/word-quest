# Flashcards: "all" means all, plus a "לא ידעתי" choice — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** In the flashcards game a round contains every word of the chosen selection (no "due today" filter), and the selection list becomes: הכל · לא ידעתי · חדשות · חלשות · חזקות · 🎯 group.

**Architecture:** The existing scope layer in `common.js` (`SCOPES`, `poolOf`, `scopeLabel`, `gameBar`) gets one new scope `missed` that exists only for the flashcards. `cards.js` stops filtering by due date, loses the tab badge, and always plays `shuffle(pool())`. "Missed" is derived from data the cards already store (`S.cards[w].d <= S.cards[w].l` means the last answer was "✗ לא ידעתי"), so no migration is needed.

**Tech Stack:** plain HTML/CSS/JS (static site), `localStorage`, Node + Playwright headless tests in `tests/`.

**Design (approved in chat, no spec file):** options in this order in the flashcards selector: `הכל` (every word, also removed ones), `❌ לא ידעתי (n)` (words whose LAST flashcard answer was "✗ לא ידעתי", any date; updates live when you answer "✓ ידעתי"), `חדשות`, `חלשות`, `חזקות` (the app-wide categories, unchanged), `🎯 <group>` (only if a group exists). The "due today" option, the red number on the cards tab and the texts about "due today" are removed. "לא ידעתי" exists only in the flashcards game: not in other games' selectors and not in the Words tab's shared choice. It includes removed (done) words because the cards game plays all words.

## Global Constraints

- Work only on branch `cards-all`. Do **not** merge to `main` or push `main`; the user merges after approval. Pushing `cards-all` is allowed only in the final task.
- UI text is Hebrew, RTL. Exact strings: option `❌ לא ידעתי (n)`; intro `N כרטיסים בסבב` (+ ` (כולל M מילים שהסרת כי למדת)` when M>0); start button `▶ התחלת סבב`; end-of-round button `▶ סבב נוסף`; empty "missed" message `אין כרטיסים שסימנת ״לא ידעתי״ 🎉`; empty other selection `אין מילים בבחירה הזו`; after a round in the "missed" selection: `נשארו עוד N כרטיסים ב״לא ידעתי״.` or `אין יותר כרטיסים ב״לא ידעתי״ 🎉`.
- "Missed" rule (from existing data, no migration): `S.cards[w.w]` exists and `d <= l`. (A "✗" answer stores `d = l = today`; every "✓" answer stores `d` strictly after `l`.) Do not change how `grade()` stores `b`, `d`, `l`.
- Selector order is `["all","missed","new","weak","strong","group"]`. `missed` is offered only for game `"cards"`; for any other game `getScope` falls back to `"all"`; the Words tab's shared selector never lists it.
- Bump the cache version (`?v=NN` in `index.html`; currently `v=47`) in the final task.
