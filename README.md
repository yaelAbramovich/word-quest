# Word Quest 🎮

משחק אישי ללימוד אוצר מילים באנגלית.

## פרסום ב-GitHub Pages

1. צרי Repository חדש ב-GitHub בשם `word-quest`.
2. העלי את כל הקבצים שבתיקייה הזו ל-repository.
3. היכנסי ל-Settings → Pages.
4. תחת **Build and deployment** בחרי:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
5. לחצי Save.
6. לאחר כמה דקות GitHub יציג כתובת לאתר.

### באייפון
פתחי את הכתובת ב-Safari → Share → Add to Home Screen.

ההתקדמות נשמרת מקומית במכשיר.
