# Word Quest 🎮

משחק אישי ללימוד אוצר מילים באנגלית. כל משחק מוגרל מחדש בכל פעם, כל מילה נשמעת ומתורגמת, והכול נשמר על המכשיר (אין שרת).

🔗 https://yaelabramovich.github.io/word-quest/

## הלשוניות

| לשונית | מה עושים |
|---|---|
| 🧩 תשבץ | משלימים מילים לפי התרגום. אחרי פתרון — שורת תוצאה קטנה, ו״פרטים״ מציג הסבר ומשפט |
| 🔎 תפזורת | מחפשים מילים בלוח. מצב אתגר: רשימה בעברית וכיוונים הפוכים |
| 🪢 איש תלוי | מקשיבים למילה ומנחשים אות אחר אות |
| 🧠 חידון | ארבעה סוגים: משמעות, הקשר, שליפה, האזנה |
| 🃏 כרטיסיות | חזרות מרווחות (spaced repetition) על כל המילים, כולל כאלה שהוסרו |
| 📋 מילים | רשימת המילים, אחוזי ידיעה, עריכה, הוספה והסרה |

## תכונות

- **קטגוריות אחידות** — כל מילה פעילה היא בדיוק אחת מ: **חדשות** (עוד לא תורגלה), **חלשות** (תורגלה, ועדיין אין אחוז או שהאחוז מתחת ל-80%), **חזקות** (יש אחוז, אחרי 10 ניסיונות, ו-80% ומעלה). אותן קטגוריות ואותם מספרים בלשונית מילים ובכל המשחקים.
- **בחירת מילים בכל משחק** — למעלה בכל משחק: הכל / חדשות / חלשות / חזקות / הקבוצה שלי, עם מספר המילים. המשחק משתמש רק במילים שנבחרו (בלי להשלים ממילים אחרות). בכרטיסיות, ״הכל״ כולל גם מילים שהוסרו.
- **בחירה אחת לכל המשחקים** — בלשונית מילים אפשר לסמן ״השתמש בבחירה אחת בכל המשחקים״; אז כל המשחקים משחקים באותן מילים והבחירה בתוכם נעולה.
- **הקבוצה שלי** — לשונית מילים ← ״בניית קבוצה״: נותנים שם חופשי, ובוחרים מילים בשתי עמודות: מימין ״נבחרו״ ומשמאל ״לא נבחרו״. לחיצה אחת על מילה מעבירה אותה לעמודה השנייה (יש חיפוש, סינון לפי קטגוריה, ״הוספת הכל מהרשימה״, ״ניקוי הבחירה״ וכפתור ״ביטול״ לפעולה האחרונה). מינימום 4 מילים. הקבוצה מופיעה ככרטיס קטן עם פס התקדמות (חזקות / חלשות / חדשות); לחיצה עליו פותחת את פירוט ההתקדמות של כל מילה, ולכל מילה יש כפתור ״✓ סיימתי ללמוד״ שמעביר אותה לרשימת המילים שהוסרו. כל המשחקים יכולים לשחק רק בקבוצה. ״סיום קבוצה״ מנקה אותה.
- **מינימום מילים** — תשבץ: 4 מילים (באורך 3–11 אותיות, מומלץ 5 ויותר). תפזורת: 3 מילים (באורך 3–10 אותיות). מילים שלא נכנסות ללוח מופיעות מתחתיו.
- **לשונית מילים** — כפתורי סינון עם ספירה: הכל, חדשות, חלשות, חזקות, ו״מילים שהוסרו״ (מילים שהסרת עם ✓: אפשר להחזיר אותן או למחוק אותן לצמיתות). ״הכל״ סופר רק מילים פעילות, כך ש״הכל״ = חדשות + חלשות + חזקות. הקבוצה מוצגת בכרטיס משלה למעלה.
- **הוראות** — כפתור **?** קטן בכל משחק פותח את ההסבר, כדי לא לתפוס מקום במסך הצר.
- **בלי חזרות** — בחידון ובאיש תלוי אותה מילה לא חוזרת בתוך 3 השאלות הבאות.
- **מדידת ידיעה** — האחוז נמדד רק בתשבץ ובחידון, על 10 הניסיונות האחרונים. 100% דורש הצלחות ב-3 ימים שונים (בפחות — מקסימום 90%). רמז או ״גלי מילה״ נחשבים כאילו לא ידעת.
- **משפטים** — לכל מילה כמה משפטים; במשחקים נבחר משפט אקראי בלי לחזור על אותו משפט פעמיים ברציפות.
- **הסרת מילים** — מילה שמכירים היטב אפשר להסיר מהמשחקים (✓), ולהחזיר בלשונית מילים. המערכת גם ממליצה על מילים להסרה.
- **קול** — הקראה באנגלית עם בחירת הקול הטבעי ביותר במכשיר, ומהירות לבחירה. כפתור 🔊 למעלה משתיק.
- **מילים להתחלה** — משתמש חדש מתחיל עם 10 מילים נפוצות (ב-words.js). מי שכבר השתמש באפליקציה שומר על המילים שהיו לו (legacy-words.js), ולא מתווספות לו מילים חדשות.
- **מחיקה לצמיתות** — כפתור 🗑 ליד כל מילה בלשונית מילים (גם ברשימת המילים שהוסרו) מוחק אותה, את ההתקדמות שלה ואת השייכות שלה לקבוצה. אי אפשר למחוק מילה פעילה כשנשארו רק 8 מילים פעילות. אין מחיקה בתוך הקבוצה, רק ברשימה המלאה.
- **חזרה לברירת מחדל** — בתחתית לשונית מילים: אחרי אזהרה ואישור, מוחק את כל מה ששמרת במכשיר הזה (מילים שהוספת, עריכות, מילים שמחקת או הסרת, הקבוצה, ההתקדמות וההגדרות) ומציג שוב את 10 מילות ברירת המחדל. אי אפשר לבטל. הכפתור ״איפוס התקדמות״ הקיים מאפס רק את ההתקדמות.

## הוספת מילים

1. **מהאפליקציה:** לשונית מילים ← ״הוספת מילים חדשות״. אפשר להעלות תמונה (זיהוי טקסט בעזרת Tesseract, צריך חיבור לאינטרנט) או להוסיף שורות ידנית. בכל שורה: מילה, תרגום, הסבר (לא חובה) ומשפטים — **כל משפט בשורה נפרדת (Enter)**. אם משאירים ריק, נחפש משפט אוטומטית ב-Wiktionary.
2. **בקוד:** עריכת `words.js`, בפורמט `{w:"english",he:"תרגום",m:"הסבר",ex:"example sentence"}`.

מילים שנוספו מהאפליקציה, עריכות והתקדמות נשמרות ב-localStorage של הדפדפן במכשיר הזה בלבד.

## מבנה הקוד

אתר סטטי בלי build: `index.html` + `style.css` + קובץ JS לכל משחק.

- `words.js` — רשימת המילים המובנית
- `common.js` — מצב משותף, סטטיסטיקות, בחירת מילים, קול, מקלדת, מתג המילים וההוראות
- `crossword.js`, `wordsearch.js`, `hangman.js`, `quiz.js`, `cards.js` — המשחקים
- `addwords.js` — לשונית מילים (רשימה, עריכה, הוספה)

## פיתוח ופרסום

- בדיקות: `node tests/run.js` (דורש Playwright; אפשר להגדיר `PW_PATH` לנתיב שלו). הבדיקות מריצות דפדפן ללא ממשק בגודל טלפון.
- הרצה מקומית: `python3 -m http.server 8791` בתיקייה ואז http://localhost:8791
- אחרי שינוי בקבצים, להעלות את מספר הגרסה ב-`index.html` (`?v=NN`) כדי שהדפדפן יטען את הקבצים החדשים.
- פרסום: GitHub Pages מ-`main` ומהתיקייה הראשית.
- באייפון: Safari ← Share ← Add to Home Screen.
