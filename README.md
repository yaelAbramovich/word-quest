# Word Quest 🎮

משחק אישי ללימוד אוצר מילים באנגלית. כל משחק מוגרל מחדש בכל פעם, כל מילה נשמעת ומתורגמת, והכול נשמר על המכשיר (אין שרת).

🔗 https://yaelabramovich.github.io/word-quest/

## הלשוניות

| לשונית | מה עושים |
|---|---|
| 🧩 תשבץ | משלימים מילים לפי התרגום. אחרי פתרון — שורת תוצאה קטנה, ו״פרטים״ מציג הסבר ומשפט |
| 🔎 תפזורת | מחפשים מילים בלוח. מצב אתגר: רשימה בעברית וכיוונים הפוכים |
| 🪢 איש תלוי | מקשיבים למילה ומנחשים אות אחר אות |
| 🧠 חידון | ארבעה סוגים: משמעות, הקשר, שליפה, האזנה |
| 🃏 כרטיסיות | חזרות מרווחות (spaced repetition) על כל המילים, כולל כאלה שהוסרו |
| 📋 מילים | רשימת המילים, אחוזי ידיעה, עריכה, הוספה והסרה |

## תכונות

- **כל המילים / רק חלשות** — מתג בראש כל משחק (נשמר לכל משחק בנפרד). מילה חלשה = מילה חדשה, או כזו עם פחות מ-80% הצלחה. אם אין מספיק מילים חלשות, המשחק משלים ממילים אחרות.
- **הוראות** — כפתור **?** קטן בכל משחק פותח את ההסבר, כדי לא לתפוס מקום במסך הצר.
- **בלי חזרות** — בחידון ובאיש תלוי אותה מילה לא חוזרת בתוך 3 השאלות הבאות.
- **מדידת ידיעה** — האחוז נמדד רק בתשבץ ובחידון, על 10 הניסיונות האחרונים. 100% דורש הצלחות ב-3 ימים שונים (בפחות — מקסימום 90%). רמז או ״גלי מילה״ נחשבים כאילו לא ידעת.
- **לשונית מילים** — כפתורי סינון עם ספירה: הכי חלשות (n), הכי חזקות (n), A-Z (n). חלשות וחזקות אף פעם לא חולקות מילה.
- **משפטים** — לכל מילה כמה משפטים; במשחקים נבחר משפט אקראי בלי לחזור על אותו משפט פעמיים ברציפות.
- **הסרת מילים** — מילה שמכירים היטב אפשר להסיר מהמשחקים (✓), ולהחזיר בלשונית מילים. המערכת גם ממליצה על מילים להסרה.
- **קול** — הקראה באנגלית עם בחירת הקול הטבעי ביותר במכשיר, ומהירות לבחירה. כפתור 🔊 למעלה משתיק.

## הוספת מילים

1. **מהאפליקציה:** לשונית מילים ← ״הוספת מילים חדשות״. אפשר להעלות תמונה (זיהוי טקסט בעזרת Tesseract, צריך חיבור לאינטרנט) או להוסיף שורות ידנית. בכל שורה: מילה, תרגום, הסבר (לא חובה) ומשפטים — **כל משפט בשורה נפרדת (Enter)**. אם משאירים ריק, נחפש משפט אוטומטית ב-Wiktionary.
2. **בקוד:** עריכת `words.js`, בפורמט `{w:"english",he:"תרגום",m:"הסבר",ex:"example sentence"}`.

מילים שנוספו מהאפליקציה, עריכות והתקדמות נשמרות ב-localStorage של הדפדפן במכשיר הזה בלבד.

## מבנה הקוד

אתר סטטי בלי build: `index.html` + `style.css` + קובץ JS לכל משחק.

- `words.js` — רשימת המילים המובנית
- `common.js` — מצב משותף, סטטיסטיקות, בחירת מילים, קול, מקלדת, מתג המילים וההוראות
- `crossword.js`, `wordsearch.js`, `hangman.js`, `quiz.js`, `cards.js` — המשחקים
- `addwords.js` — לשונית מילים (רשימה, עריכה, הוספה)

## פיתוח ופרסום

- הרצה מקומית: `python3 -m http.server 8791` בתיקייה ואז http://localhost:8791
- אחרי שינוי בקבצים, להעלות את מספר הגרסה ב-`index.html` (`?v=NN`) כדי שהדפדפן יטען את הקבצים החדשים.
- פרסום: GitHub Pages מ-`main` ומהתיקייה הראשית.
- באייפון: Safari ← Share ← Add to Home Screen.
